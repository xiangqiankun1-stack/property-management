# 三、BUG列表及修复情况

| 分类      | Bug 描述                            | 修复方案                                  |
| --------- | ----------------------------------- | ----------------------------------------- |
| Maven依赖 | Maven 编译插件下载失败              | 使用  spring-boot-starter-parent 继承管理 |
| Maven依赖 | PageHelper 与 MyBatis-Plus 分页冲突 | 移除 PageHelper，统一使用 MyBatis-Plus    |
| 后端代码  | Repair 实体缺少字段导致编译报错     | 补充 completeTime、workerId 等 5 个字段   |
| 后端代码  | Mapper 接口无法解析                 | 确认并添加 @Mapper 注解                   |
| 接口对接  | 登录返回格式不完整                  | 返回 token +  userInfo                    |
| 接口对接  | 登录传参方式不匹配导致 415          | 前端改用 JSON 格式传参                    |
| 接口对接  | 数据格式不匹配                      | 响应拦截器统一处理                        |
| 前端      | 浏览器缓存导致代码不生效            | 清除/禁用浏览器缓存                       |
| 前端      | 表格数据显示不全                    | 补充完整列及字段映射                      |
| 前端      | 异步错误未捕获（含表单验证）        | 添加 try-catch + 全局错误处理器           |
