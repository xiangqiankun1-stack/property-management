# 智慧物业管理系统用户手册

# 1. 系统简介

智慧物业管理系统是一套基于 **Spring Boot + Vue3** 开发的物业管理平台，主要用于物业公司日常业务管理，实现用户权限管理、小区管理、房屋管理、业主管理、报修管理、投诉管理、费用管理及数据统计等功能，提高物业管理效率和服务质量。

系统采用前后端分离架构，支持浏览器访问，无需安装客户端，具有操作简单、界面友好、易于维护等特点。

# 3. 系统安装部署

## 3.1 获取项目源码

使用 Git 克隆项目：

```bash
git clone https://gitee.com/link50k/property-management.git
```

项目目录结构如下：

```text
property-management
│
├── backend        Spring Boot 后端
├── frontend       Vue3 前端
└── docs           项目文档
```

------

## 3.2 创建数据库

导入项目提供的 SQL 文件：

```text
database/schema.sql与init_data.sql
```

导入完成后即可生成系统所需的数据表及初始化数据。

------

## 3.3 配置后端

进入 backend 项目，修改数据库连接配置：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/property_management
    username: root
    password: 你的数据库密码
```

------

## 3.4 启动后端

使用 IntelliJ IDEA 打开 backend 项目。

运行启动类：

```text
PropertyManagementApplication
```

启动成功后出现类似信息：

```text
Started PropertyManagementApplication
```

默认访问地址：

```text
http://localhost:8080
```

------

## 3.5 启动前端

进入 frontend 目录：

```bash
cd frontend
```

安装依赖：

```bash
pnpm install
```

启动项目：

```bash
pnpm run dev
```

启动成功后浏览器访问：

```text
http://localhost:5173
```

即可进入系统登录页面。

# 5. 功能使用说明

## 5.1 登录

**操作步骤：**

1. 输入用户名。
2. 输入密码。
3. 点击"登录"按钮。
4. 登录成功后进入系统首页。

------

## 5.2 用户管理

用于维护系统用户信息。

主要功能：

- 新增用户
- 修改用户
- 删除用户
- 查询用户
- 分页浏览用户

**操作流程：**

1. 进入【系统管理】→【用户管理】。
2. 点击"新增用户"。
3. 输入用户信息。
4. 点击"保存"完成新增。

------

## 5.3 角色管理

用于配置系统角色。

支持：

- 新增角色
- 修改角色
- 删除角色
- 分配权限

管理员可根据实际业务创建不同角色，例如：

- 系统管理员
- 物业工作人员
- 财务人员

------

## 5.4 小区管理

- 修改小区
- 删除小区

填写内容包括：

- 小区名称
- 地址
- 面积
- 开发商
- 物业公司

------

## 5.5 楼栋管理

用于维护楼栋信息。

支持：

- 新增楼栋
- 修改楼栋
- 删除楼栋

新增楼栋时需选择所属小区。

------

## 5.6 房屋管理

用于维护房屋信息。

支持：

- 新增房屋
- 修改房屋
- 删除房屋
- 查询房屋

房屋信息包括：

- 房号
- 楼层

## 5.7 业主管理

用于维护业主信息。

支持：

- 新增业主
- 修改业主

```text

      ↓

      ↓
```

- 新建报修
- 查看报修
- 派单
- 修改状态
- 查看评价

用于生成物业账单。

- 账单编号

- 缴费状态

系统提供统计分析功能。

# 6. 常见问题解答（FAQ）

## Q1：系统无法启动怎么办？

**可能原因：**

- JDK 未正确安装。
- Maven 依赖未下载完成。
- 后端端口被占用。

**解决方法：**

- 检查 JDK 版本是否符合要求。
- 执行 `mvn clean install` 重新下载依赖。
- 修改 `application.yaml` 中的端口号，或关闭占用端口的程序。

------

## Q2：数据库连接失败怎么办？

**可能原因：**

- MySQL 服务未启动。
- 数据库用户名或密码错误。
- 数据库不存在。

**解决方法：**

- 启动 MySQL 服务。
- 检查数据库连接配置。
- 确认已创建 `property_management` 数据库并导入初始化 SQL。

------

## Q3：前端页面无法访问怎么办？

**可能原因：**

- 前端未启动。
- Node.js 或 pnpm 未正确安装。
- 前端端口被占用。

**解决方法：**

- 执行 `pnpm install` 安装依赖。
- 执行 `pnpm run dev` 启动项目。
- 修改 Vite 配置中的端口号。

------

## Q4：登录后提示无权限访问页面怎么办？

**可能原因：**

- 当前账号未分配对应角色。
- 角色未配置菜单权限。

**解决方法：**

- 使用管理员账号登录。
- 在【角色管理】中为用户分配角色。
- 在【权限管理】中配置角色对应权限。

------

## Q5：新增数据后列表未更新怎么办？

**可能原因：**

- 页面缓存未刷新。
- 数据提交失败。

**解决方法：**

- 点击页面刷新按钮或重新查询。
- 检查后端接口返回结果。
- 查看浏览器开发者工具（F12）确认请求是否成功。

------

## Q6：如何恢复误删的数据？

系统采用逻辑删除机制，误删的数据不会立即从数据库中移除。管理员可根据实际情况在数据库中恢复数据，或通过后台管理功能重新启用相关记录（如系统提供恢复功能）。
